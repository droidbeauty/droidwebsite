# Droid Beauty website

A small static website for Droid Beauty, inspired by the restrained, text-first structure of mnmlist.

## Files

- `index.html` — content and links
- `styles.css` — layout, typography and responsive styles
- `.nojekyll` — tells GitHub Pages to serve the files directly

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload all files from this folder to the repository root.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then save.

A normal project repository will be published at:

`https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`

For a root personal site, name the repository:

`YOUR-USERNAME.github.io`

## Editing the site

Most changes only require editing `index.html`:

- Change the main headline and introduction near the top.
- Edit app names, descriptions or Play Store URLs inside each category.
- Replace the email and Instagram links in the About section.

Typography, spacing and colors are controlled in `styles.css` under `:root` and the heading rules.
